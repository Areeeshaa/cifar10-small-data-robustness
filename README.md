# CIFAR-10 with Only 500 Training Images: Robustness to Distribution Shift

An Inception-style CNN trained **from scratch** on 400 CIFAR-10 images (plus 100 for validation) and tested on a shifted version of the CIFAR-10 test set (rotation, brightness/contrast changes, occlusion and one hidden corruption).

Main result: **27.0% ± 0.45** shifted-test accuracy (mean ± std over 3 seeds), compared with **16.3% ± 0.7** for the baseline with no augmentation.

## How to reproduce the results

No data files are needed. CIFAR-10 is downloaded automatically by `torchvision`, and the shifted test set is generated by code with a fixed seed.

**Option A: Google Colab (recommended)**
1. Open `notebook.ipynb` in Google Colab (upload it, or use "Open notebook" then GitHub).
2. Set **Runtime, then Change runtime type, then T4 GPU**.
3. Run **Runtime, then Run all**. The packages Colab does not already have are listed in `requirements.txt`.
4. The full run (all ablation configurations with 3 seeds) takes roughly 20 to 30 minutes on a GPU.

**Option B: Local machine**
```bash
git clone <your-repo-url>
cd <your-repo-name>
pip install -r requirements.txt
jupyter notebook notebook.ipynb
```
Then choose **Kernel, then Restart & Run All**. A GPU is strongly recommended; on CPU the run will be very slow.

GPU runs can differ by a few tenths of a percent between machines even with fixed seeds. The seeds, splits and conclusions stay the same.

## Datasets

| Set | How it is built |
|---|---|
| `train_small` | 500 images from the CIFAR-10 training set, 50 per class (seed 123) |
| training / validation | `train_small` split 400 / 100, 40 / 10 per class (seed 0) |
| `clean_test` | the original 10,000 CIFAR-10 test images |
| `shifted_test` | the 10,000 test images with random rotation (up to ±25°), brightness and contrast changes, a random black rectangle covering about 25% of the image, and one hidden corruption (seed 2024) |

The test sets are **never** used for training, validation or hyperparameter tuning. They are used only to report final results.

> **Note on the hidden corruption:** the function `hidden_corruption()` in the notebook is where the hidden corruption is implemented. Replace its body with the official version if one was provided, then re-run the whole notebook so all results are updated.

## Random seeds (for reproducibility)

| Purpose | Seed |
|---|---|
| Choosing the 500 `train_small` images | 123 |
| 400 / 100 train / validation split | 0 |
| Shifted-test corruption pipeline | 2024 |
| Corrupted validation set (used for model selection) | 777 |
| Model training runs (mean ± std reported over these) | 0, 1, 2 |

Python, NumPy and PyTorch are all seeded by `set_seed()` at the start of every training run.

## Model

- Stem convolution, then 3 Inception modules (parallel 1×1, 1×1→3×3, 1×1→5×5 and pool→1×1 branches), global average pooling, dropout, linear layer.
- 145,938 trainable parameters (limit: 1,000,000).
- BatchNorm after every convolution; dropout (0.3) after global pooling.

## Training setup (final model)

- Optimiser AdamW, learning rate 1e-3, weight decay 5e-4, OneCycle schedule, batch size 32, maximum 60 epochs.
- Early stopping and best-epoch selection on a validation score (clean validation images plus a corrupted copy of them).
- Augmentation applied on the fly to training data only:
  - Geometric: random crop (reflect padding 4), horizontal flip, rotation ±25°, translation 0.1, scale 0.9 to 1.1
  - Photometric: ColorJitter, Gaussian blur, Gaussian noise, random grayscale, channel shuffle
  - Random Erasing (black fill, p = 0.7, 5% to 30% of the image)
- Mixup and label smoothing were tested but not used in the final model.

## Results (mean ± std over 3 seeds)

| Configuration | Val Acc (%) | Clean Test (%) | Shifted Test (%) |
|---|---|---|---|
| No augmentation | 56.0 ± 0.8 | 44.7 ± 1.2 | 16.3 ± 0.7 |
| Geometric only | 50.7 ± 0.9 | 42.6 ± 1.0 | 19.3 ± 0.3 |
| Photometric only | 55.3 ± 4.6 | 44.3 ± 3.6 | 16.4 ± 0.5 |
| Geometric + photometric | 52.0 ± 1.4 | 42.9 ± 0.4 | 20.9 ± 0.6 |
| + Cutout / Random Erasing | 46.3 ± 1.7 | 39.9 ± 0.5 | 27.0 ± 0.4 |
| + Mixup + label smoothing | 47.3 ± 1.9 | 38.5 ± 1.2 | 25.3 ± 0.6 |
| **Final model** (= + Cutout) | 46.3 ± 1.7 | 39.9 ± 0.5 | **27.0 ± 0.4** |

**Largest gain:** Random Erasing / Cutout (+6.1 points over geometric + photometric). It matches the rectangular occlusion in the shifted test.
**Trade-off:** augmentation lowers clean accuracy in exchange for robustness under shift.

The final model was chosen using validation data only (not test accuracy).

## Rules compliance

- No pretrained weights; everything is trained from scratch.
- At most 1,000,000 trainable parameters (printed in the notebook).
- Includes Inception-style modules.
- Hyperparameters chosen on the validation split only; test sets used only for final reporting.
- Augmentation is applied on the fly inside the dataset; no augmented images are saved to disk.
- Maximum 60 epochs, fixed seeds, 3 seeds reported as mean ± std.

## Other results in the notebook

- **Error analysis:** per-class accuracy, normalized confusion matrix, 8+ misclassified images with explanations.
- **Hidden-corruption test:** accuracy when only the hidden corruption is applied to the clean test set.
- **Test-time augmentation (bonus):** averaging softmax over 8 flipped and shifted copies.
